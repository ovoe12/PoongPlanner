HTML 기반 스케줄 관리 앱 계획서

우선순위 점수로 일정을 자동 정렬하는 달력 앱

일정의 카테고리, 난이도, 남은 기한을 점수화하고 점수가 높은 일정일수록 달력과 우선순위 목록의 상단에 표시한다. 사용자는 오늘 가장 먼저 처리해야 할 일을 색상과 순서로 빠르게 판단할 수 있다.

핵심 기능 일정 등록, 달력 표시, 점수 계산, 우선순위 정렬, 색상 구분
카테고리 우선순위 과제 제출 > 수행 > 시험 > 약속 > 기타 일정
권장 구현 방식 HTML + CSS + JavaScript + localStorage로 먼저 제작

1. 앱 목표와 사용자 흐름

일정 입력

제목, 날짜, 카테고리, 난이도, 마감일을 입력한다. 같은 날짜에 여러 일정이 있어도 점수순으로 정렬한다.

자동 점수 계산

카테고리 기본점수, 난이도 가중치, 남은 기한 긴급도를 합산해 최종 점수를 만든다.

우선순위 표시

점수가 높은 일정은 빨간색 계열로 상단에 표시하고, 낮은 일정은 초록색 또는 회색으로 표시한다.

2. 점수 산정 규칙

최종 점수 = 카테고리 기본점수 + 난이도 점수 + 기한 긴급도 점수

카테고리 점수는 사용자가 요청한 중요도 순서를 반영해 과제 제출, 수행, 시험, 약속, 기타 일정 순으로 높게 잡는다. 난이도와 마감 임박도는 같은 카테고리 안에서 우선순위를 더 정확히 나누는 역할을 한다.

난이도 상 / 중 / 하 30 / 20 / 10 어려운 일일수록 더 일찍 처리하도록 점수를 높인다.

5. 단계별 구현 방안

기본 HTML 구조 만들기

상단에는 상태 표시와 월 제목을 두고, 본문에는 월간 달력 또는 업무 목록이 표시되도록 만든다. 하단에는 달력, 업무 탭을 배치한다.

입력 데이터 정의

일정 객체는 id, title, category, difficulty, dueDate, memo, score를 가진다.

점수 계산 함수 작성

카테고리 기본점수, 난이도 점수, 오늘 날짜와 마감일 차이로 구한 기한 점수를 더해 최종 점수를 계산한다.

달력 렌더링 구현

현재 월의 6주 날짜 칸을 모두 만들고, 이전 달과 다음 달 일부 날짜까지 함께 보여줘 한 달 일정 흐름이 끊기지 않게 한다.

업무 탭 페이지 구현

하단 업무 탭을 누르면 전체 일정을 하나의 배열로 모은 뒤 score 기준 내림차순으로 정렬한 목록을 보여준다.

색상과 상단 표시 적용

점수 구간과 카테고리에 따라 CSS 클래스를 부여하고, 달력 일정 막대와 업무 목록에 같은 우선순위 색상 기준을 적용한다.

저장 기능 추가

처음에는 localStorage에 저장해 새로고침 후에도 일정이 유지되도록 한다. 이후 필요하면 서버와 데이터베이스로 확장한다.

수정, 삭제, 필터 기능 추가

등록된 일정을 클릭하면 상세 내용을 확인하고 수정 또는 삭제할 수 있게 한다. 카테고리별 필터와 완료 표시 기능도 추가한다.

6. JavaScript 핵심 로직 예시

score = categoryScore[category] + difficultyScore[difficulty] + deadlineScore(daysLeft)

같은 날짜에 여러 일정이 있으면 events.sort((a, b) => b.score - a.score) 방식으로 정렬한다. 달력 탭에는 날짜별 정렬 결과를 출력하고, 업무 탭에는 전체 일정 배열을 같은 방식으로 정렬해 출력한다.

7. 완성 전 확인 목록

  • 과제 제출, 수행, 시험, 약속, 기타 일정 순서로 기본 점수가 적용되는지 확인한다.
  • 난이도가 높을수록 같은 카테고리 안에서 점수가 올라가는지 확인한다.
  • 마감일이 가까울수록 우선순위가 높아지는지 확인한다.
  • 점수 구간별 색상이 달력과 업무 목록에 일관되게 표시되는지 확인한다.
  • 하단의 달력 탭과 업무 탭을 눌렀을 때 화면이 정상적으로 전환되는지 확인한다.
  • 새로고침 후에도 일정이 유지되는지 확인한다.
  • 모바일 화면에서도 달력과 업무 목록이 겹치지 않고 읽히는지 확인한다.
